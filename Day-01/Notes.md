## Day 01 — Introduction to Programming

**PART 1 — Understanding programming**

**1. What is programming?**

Programming is the process of writing instructions that tell a computer what to do.

Programming is the process of creating instructions that enable a computer to perform specific tasks.

**Think about it this way:**

Imagine asking someone to prepare a cup of tea.

**You would give them instructions:**
1. Boil water.
2. Put a teabag into a cup.
3. Pour hot water into the cup.
4. Add sugar.
5. Stir.
6. Serve.

**For example, Python:**

print("Hello, Python!")

**Output:**

Hello, Python!

**2. What is Python?**

Python is a high-level, general-purpose programming language known for its readable syntax.

**Python is used in:**
- Web development.
- Artificial intelligence.
- Data science.
- Automation.
- Cybersecurity.
- Software development.

**Why do we use Python?**
1. It has relatively simple syntax.
2. It is easy to read and understand.
3. It supports different programming approaches.
4. It has many built-in functions and libraries.
5. It is useful for solving real-world problems.

**Important:** Python is an interpreted language. You can execute Python code using the Python interpreter.

**3. What is an algorithm?**

An algorithm is a step-by-step procedure used to solve a particular problem.

**example:**

**Problem:** Calculate the sum of two numbers.

Before writing Python code, we plan the solution.

**Algorithm:** Adding two numbers
1. Start.
2. Enter the first number.
3. Enter the second number.
4. Add the two numbers.
5. Display the result.
6. Stop.

**This is how programmers think:**

Problem → Algorithm → Code → Output

**PART 2 — Understanding print() and input()**

**Print() example:**

print("Hello, Python!")

**Let's understand the code:**
- print is a built-in Python function.
- Parentheses () contain what we want to display.
- Quotation marks "" indicate text (a string).

**Input() example:**

name = (input("Enter your name: "))

print("Hello Welcome", name)

**Let's break it down:**
- input() asks the user to enter information.
- name stores the entered value.
- print() displays the result.
